# StudyCrew Landing Page

> **⚠️ Note:** This repository only serves the homepage for the StudyCrew project. The main open-source StudyCrew platform has been archived and is no longer actively developed.

## Background
The original StudyCrew open-source project was created with the goal of building an accessible online education platform. Unfortunately, due to development challenges and declining activity in the repository, the platform itself was not completed. The [homepage](https://studycrew.world/) is maintained in this repo as an informational site.
